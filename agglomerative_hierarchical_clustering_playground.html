Agglomerative Hierarchical Clustering

Simulasi interaktif untuk memahami proses bottom-up clustering: mulai dari setiap data sebagai cluster sendiri, menghitung jarak antar-cluster, memilih jarak terkecil, lalu menggabungkan cluster secara bertahap.

Input Data

Format: Label, x, y. Satu data per baris.

Rumus Dasar

d(P,Q) = √((x₂-x₁)² + (y₂-y₁)²)

Rumus Linkage

single(Cᵢ,Cⱼ) = min d(a,b), a ∈ Cᵢ, b ∈ Cⱼ

Catatan: contoh ini memakai jarak Euclidean untuk data 2 dimensi.

Dataset

Ide Algoritma

  1. Anggap setiap data sebagai satu cluster awal.
  2. Hitung jarak antar-cluster berdasarkan metode linkage yang dipilih.
  3. Pilih dua cluster dengan jarak paling kecil.
  4. Gabungkan kedua cluster tersebut menjadi cluster baru.
  5. Ulangi sampai semua data tergabung menjadi satu cluster.

Hasil Akhir

Matriks Jarak Antar-Data Awal

Matriks ini dihitung menggunakan jarak Euclidean antar-titik sebelum proses penggabungan cluster.

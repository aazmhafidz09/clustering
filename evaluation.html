Evaluasi Clustering

Playground utama Perhitungan K-Means
K = 3

Internal Evaluation

Mengukur kualitas cluster hanya dari data dan cluster hasil algoritma.

Sum Square Error SSE = ∑j=1..K ∑xi in Cj ||cj - xi||2
Silhouette coefficient s(i) = (b(i) - a(i)) / max(a(i), b(i)). a(i) adalah jarak rata-rata ke cluster sendiri, b(i) adalah jarak rata-rata terkecil ke cluster lain.
Davies-Bouldin & Dunn DB rendah lebih baik. Dunn tinggi lebih baik karena jarak antar cluster besar dan diameter cluster kecil.

External Evaluation

Membandingkan cluster prediksi dengan label asli yang diketahui.

Purity Purity = (1 / N) ∑cluster mayoritas label asli di cluster.
Mutual Information MI mengukur seberapa banyak informasi label asli dijelaskan oleh cluster prediksi. NMI menormalisasi MI ke rentang 0 sampai 1.
F-Measure & Jaccard Dihitung dari pasangan titik: TP, FP, FN. F-Measure menyeimbangkan precision dan recall; Jaccard = TP / (TP + FP + FN).
Isi warna = cluster prediksi Ring = label asli Centroid Garis titik terpilih untuk a(i) dan b(i)
